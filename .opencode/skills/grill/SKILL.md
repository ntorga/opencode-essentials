# Grill

Interview the user to find gaps in a plan, decision, or idea. Keep the process
short. Do not create design trees or plan files.

## Procedure

1. State the goal in one sentence.
2. Separate settled facts from open decisions. Find facts with tools instead
   of asking the user for them.
3. Ask up to three questions in one round. State a recommendation when the
   answer has a real trade-off.
4. Wait for the user's answers. Use them to choose the next questions.
5. Stop after eight questions total. If decisions remain open, list them as
   assumptions. Do not ask more questions.
6. When the decisions are clear, summarize them and ask the user to confirm
   the shared understanding. Do not act before confirmation.

Each question must resolve a decision that affects the result. Do not ask for
details that tools or project files can answer. Put the recommended option
first when you give choices.

## Round format

```text
Q1. <Decision>: <Question and useful choices>

Recommendation: <Best option and reason>
```

Number questions across the whole interview. Stop when the total reaches
eight, even if another round could help.
