This repository contains an OpenCode plugin suite, local OpenCode additions,
and project reference material.

## Summary

- .agents/ — project instructions, coding rules, and workflow skills.
- .git/ — repository metadata.
- .gitignore — excludes local configuration, dependencies, and working files.
- .ignore — contains unignore entries for .agents/, .memory/, TODO.md, and tmp/.
- .memory/ — local agent memory, plans, reviews, sessions, and todo records.
- .opencode/ — local plugin loader, native skills, and slash commands.
- AGENTS.md — project coding and workflow instructions.
- biome.json — Biome file selection and formatting settings.
- CHANGELOG.md — dated project change history.
- docs/ — user-facing feature map.
- node_modules/ — installed root dependencies.
- package-lock.json — root npm dependency lockfile.
- package.json — package metadata and development scripts.
- README.md — project overview, implemented features, and development setup.
- src/ — server and TUI plugin implementation.
- TODO.md — confirmed work, open ideas, and implementation findings.
- tmp/ — source trees named opencode-src/, os/, and tk/.
- tsconfig.json — root TypeScript compiler settings.
- tui.json — TUI plugin registrations and options.

## Constraints

- Server and TUI plugin entries MUST use their separate host configuration files.

## Guidance

- Run project checks with the scripts in package.json.
