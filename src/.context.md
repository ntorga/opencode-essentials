`src/` contains one server entry, four TUI entries, shared feature logic,
state, and validated input types. OpenCode loads the local wrapper guard
through `.opencode/plugins/exec-wrapper-guard.ts`.

## Constraints

- Plugin entry modules MUST export the hook for one host. The suite entries
  export `server` or `tui`; the wrapper guard exports its own plugin.
- External strings and numbers MUST pass a constructor in `valueObject/`
  before they reach feature logic.
- Feature changes MUST use the shared state file so toggles take effect
  without restarting OpenCode.
- Compactors MUST remain event-driven and use one-shot timers.
- State writes MUST refuse unreadable or invalid state files.

## Guidance

- Register each feature row in `features/registry.ts`. The server uses rows
  with `buildHooks`; the TUI uses the registry for `/essentials`.
- `combineHooks` runs feature handlers sequentially. A thrown handler stops
  the remaining handlers for that event.
