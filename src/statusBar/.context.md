This directory computes the content of the shared status bar: response
metrics, the idle-time anchor, and the idle clock line with its color. The
`usage-status.tsx` entry renders the rows these modules produce.

## Summary

- idleClockStatus.ts — resolves idle clock settings and the active session state.
- idleWaiting.test.ts — tests idle anchors, elapsed time, and display colors.
- idleWaiting.ts — selects and formats the TUI idle-time anchor.
- usageStatus.test.ts — tests response selection, timing, and formatting.
- usageStatus.ts — validates and formats completed-response metrics.

## Constraints

- Rendering lives in the entries; these modules return plain data and strings.
- External values MUST pass valueObject constructors or document parsers
  before these modules use them.

## Guidance

- Read the response window through `../documents/completedAssistantMessage.ts`
  instead of probing raw payloads.
