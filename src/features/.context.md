This directory defines five feature rows for the essentials plugin. Server
features provide hooks; TUI-only features provide metadata for the feature
dialog and their separate TUI entries.

## Summary

- feature.ts — defines suite feature contracts and feature context.
- idle-auto-compactor.test.ts — tests timer lifecycle, gates, skips, and failures.
- idle-auto-compactor.ts — server feature that compacts idle sessions.
- idle-clock.ts — TUI-only feature row for the idle clock.
- permission-assistant.ts — feature row for permission decisions and notifications.
- registry.ts — lists five rows for server hooks and TUI controls.
- sessionSummarizer.ts — shares the session summary request between compactors.
- token-ceiling-compactor.test.ts — tests idle checks, limits, and failures.
- token-ceiling-compactor.ts — server feature that compacts at a token ceiling.
- usage-status.ts — feature row for the response usage display.

## Constraints

- TUI-only feature rows MUST omit `buildHooks`; server setup skips rows without it.
- Server feature handlers MUST read the shared feature state at decision points.
- Compactor behavior MUST remain event-driven; idle timers are one-shot.
- Session IDs MUST pass `newSessionId` before client API calls.

## Guidance

- Define a feature row here and register it in `registry.ts`.
- Keep feature-specific behavior in its own module.
